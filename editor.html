Portfolio editor

How this works. Nothing here changes the live site by itself. Make your changes, press Get the new work.js, then paste it into work.js on GitHub.
  1. Reorder: use ↑ and ↓ on each page.
  2. New page: first upload the image into the work folder on GitHub, then press + Add a page and type its name, e.g. work/my-new-campaign.webp.
  3. Video: press + Video area on a page, drag a box over the thumbnail, then paste the YouTube, Google Drive, Instagram or Vimeo link.
  4. Publish: Get the new work.js → Copy → on GitHub open work.js → pencil icon → select all → paste → Commit changes. Live in about a minute.
